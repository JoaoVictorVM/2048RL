Rodando localmente

O modo de jogo humano funciona de imediato. Assistir ao agente e ver métricas exige pelo menos um treino gravado em disco.

  1. Treine um agente (gera checkpoints e métricas em ./data): go run ./cmd/train --episodes=1000
  2. Suba o servidor e abra esta página: go run ./cmd/server
